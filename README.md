One horror sentence, delivered dead calm: "I told the thing in the attic it could stay if it kept quiet, and it has — except on nights when I hear it practicing my laugh." The narrator stays perfectly chill about sharing the house with something unseen, and that relaxed tone is exactly what makes the last word land.

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt`. The line is 127 characters long, inside the competition's 1–200 character limit.
